02 / AT THE MIXER

Install with the full picture.

This page prepares a file; it does not connect to or flash the mixer. Installation is a separate hardware experiment. Establish a stock baseline, back up settings and arrange a device-specific recovery route first. Preserved boot code and previous TAP rollback observations do not guarantee recovery.

Read the hardware preparation guide ↗

  1. Keep a clearly labelled copy

    Save MXPLUS_MAINLINE_UNTESTED.bin and its receipt. In a separate installation folder, duplicate the verified candidate and name that copy MX-1_UPD.BIN. Keep the stock file elsewhere. Renaming does not change the hash.

  2. Enter update mode

    With the MX-1 off, hold TAP while switching it on. Connect the computer to the mixer’s USB-B port. Open the MX-1 drive that appears.

  3. Copy, then eject

    Copy only the prepared MX-1_UPD.BIN into the drive’s top level. Wait for copying to finish, eject the drive through the operating system, then unplug USB.

  4. Run the update

    Press TAP. Keep power connected while the pads indicate progress. Wait for Fin before switching off. If the expected sequence fails, stop and use the established recovery plan.

  5. Check the exact candidate

    Start with monitoring muted. Check ordinary mixer operation, then routing, mastering and USB in small steps. Keep the hash, settings, connections and observations with the bench record. The displayed Roland version cannot identify mxplus.

The transfer sequence follows Roland’s official v1.05 update procedure. Using a renamed copy of this experimental candidate is an mxplus step, not a Roland-supported update.

03 / GOOD TO KNOW

Before you press play.

Does my firmware leave this browser?

No. The page downloads the patch and processes your chosen firmware in browser memory. It has no upload endpoint, analytics, external scripts or account requirement. GitHub serves the page and assets; the original and patched files stay on your computer.

Why was my file rejected?

Only the exact original MX-1 v1.05 file is accepted. ZIP archives, other models or revisions, truncated files and already patched files will fail. Extract a fresh official download; do not try to bypass the check.

Is this ready for every MX-1 setup?

No. This is an experimental preview with incomplete hardware acceptance. Earlier limited tests do not establish broad compatibility, safe upgrades or recovery from all failures. See the remaining validation work.

Where are the controls and support notes?

Read the routing guide, mastering layout and USB limitations. Report issues with your candidate hash and setup on GitHub.
